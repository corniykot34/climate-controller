# GCT USB4105 — Mechanical Reference

**Role:** USB-C charging + service/data receptacle  
**Project status:** SELECTED  
**Manufacturer drawing:** https://gct.co/files/drawings/usb4105.pdf  
**Manufacturer product page:** https://gct.co/connector/usb4105

## Verified mechanical data

- USB Type-C receptacle, USB 2.0.
- Horizontal, side-entry, PCB top-mount.
- Body length: **7.35 mm**.
- Maximum overall width from drawing: **8.94 mm**.
- Profile above PCB: **3.31 mm**.
- Recommended PCB layout is provided in the manufacturer drawing.
- PCB-layout drawing tolerance: **±0.05 mm** where stated.
- Through-hole shell-stake variants are available.

## Packaging rules

- Port is accessed from the **bottom edge** of the product.
- Reserve **0.3–0.5 mm** internal packaging clearance.
- Current enclosure-opening allowance: about **0.25–0.30 mm per side** around the shell, to be refined during enclosure DFM.
- External plug approach must remain unobstructed.
- Model the connector body / shell / board-edge relationship, not a breakout board.
