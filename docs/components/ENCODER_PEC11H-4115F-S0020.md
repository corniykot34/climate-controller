# Bourns PEC11H-4115F-S0020 — Mechanical Reference

**Role:** physical rotary encoder with push switch  
**Project status:** SELECTED  
**Manufacturer source:** https://www.bourns.com/docs/product-datasheets/pec11h.pdf

## Part-number decoding

- PEC11H
- terminal configuration: **4 = PC pin horizontal / rear facing**
- detent option: **1 = 20 detents**
- shaft length: **15 = 15.0 mm**
- shaft style: **F = metal flatted shaft**
- switch: **S = push momentary**
- resolution: **0020 = 20 pulses / 360°**

## Verified mechanical data

- Main body width: approximately **11.8 mm**.
- Main body depth/second envelope dimension: approximately **12.8 mm**.
- Rear depth from mounting-surface region: approximately **6.5 mm**.
- Shaft diameter: **Ø6.0 mm**.
- Shaft length L: **15.0 mm**.
- For L=15 mm drawing table: **LB = 5.0 mm**, **F = 5.0 mm**.
- Bushing thread: **M7 × 0.75**.
- Push-switch travel: **0.5 ± 0.3 mm**.
- General drawing tolerance: dimensions <10 mm typically ±0.3 mm; 10–100 mm typically ±0.5 mm.

## Packaging rules

- Encoder must remain mechanically close to the rotary wheel.
- Allow **0.5 mm** packaging clearance around the body.
- Do not stack the encoder behind the battery if avoidable.
- Preserve axial push travel.
- Shaft engagement, nut/washer/bushing, front-cover thickness and wheel hub must be checked as one mechanical stack.
